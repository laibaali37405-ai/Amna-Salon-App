# Amna Salon App

A professional mobile application built for salon management, helping users/owners manage appointments and services efficiently.
Key Features:
•	Dynamic Content Management: Integrated with Firebase Firestore, allowing real-time updates for exclusive deals and services without needing an app redeploy.
•	Admin Command Center: A secured Admin Mode to manage business offerings dynamically from within the app.
•	Immersive Media Experience: Features a high-end video-based gallery and an interactive detailed photo album using Flutter’s advanced gesture and media controllers.
•	Direct Booking: Seamless integration with WhatsApp API for instant customer-to-business communication.
This project showcases my ability to handle complex state management, cloud database integration (Firebase), and creating premium, user-centric designs.
